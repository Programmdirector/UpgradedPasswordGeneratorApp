# UpgradedPasswordGeneratorApp
RU
«Password Generator» — одностраничного веб-приложения на React + TypeScript + Tailwind CSS, работающего полностью на стороне клиента. Приложение использует компонентный подход React с функциональными компонентами и хуками, хранит данные в localStorage, и построено с помощью сборщика Vite. Архитектура оптимизирована для приватности (данные не покидают устройство), простоты развёртывания (статические файлы) и производительности (виртуальный DOM, CSS-анимации).

Для запуска приложения в консоли прописать: 
npm run build
npm run dev

EU
"Password Generator" is a single-page web app built with React + TypeScript + Tailwind CSS, running entirely on the client side. The app uses a component-based React approach with functional components and hooks, stores data in localStorage, and is built with the Vite bundler. Its architecture is optimized for privacy (data doesn’t leave the device), easy deployment (static files), and performance (virtual DOM, CSS animations).  

To run the app, type in the console:  
npm run build  
npm run dev
